# 🏰 Sir Curty - Frontend

Bem-vindo ao front-end do **Sir Curty**, o teu encurtador de links épico com temática medieval!

Esta aplicação foi desenvolvida com React e Vite para proporcionar uma experiência de utilizador mágica, rápida e segura. A interface guia os utilizadores através da forja de novos pergaminhos (links curtos) com a ajuda do nosso mascote, o Sir Curty.

## ✨ Funcionalidades Mágicas

- **Interface Medieval & Responsiva:** Design temático "pergaminho e castelo", construído com Tailwind CSS.
- **Tema Claro / Escuro:** Alterna entre o dia soalheiro do reino e a noite iluminada por tochas.
- **Validação de Feitiços (Zod):** Os links inseridos são rigorosamente inspecionados antes de serem submetidos ao servidor.
- **Feitiços Avançados:** 
  - ✏️ **Slugs Personalizados:** Cria nomes únicos para os teus links.
  - 🔥 **Visualização Única:** Links que se autodestroem após o primeiro acesso.
  - 🔒 **Proteção com Senha:** Tranca o destino a sete chaves.
- **Integração Real (React Query & Fetch):** Comunicação em tempo real com o backend NestJS/PostgreSQL para forjar e consultar pergaminhos.
- **Dashboard do Reino:** Acompanha os pergaminhos criados, cliques e segurança.

## 🛠️ O Arsenal (Tecnologias)

A forja do Sir Curty utiliza as seguintes ferramentas:

- **React 18**
- **Vite**
- **TypeScript**
- **Tailwind CSS v4**
- **Zod** (Validação)
- **React Router** (Navegação)
- **TanStack React Query** (Gestão de estados da API)

## 🚀 Como acender as tochas (Instalação)

Para correres este castelo na tua máquina local:

1. Certifica-te de que a API (Backend) já está a correr.
2. Navega para a pasta do frontend:
   \`\`\`bash
   cd frontend
   \`\`\`
3. Instala as dependências:
   \`\`\`bash
   npm install
   \`\`\`
4. Inicia o servidor de desenvolvimento:
   \`\`\`bash
   npm run dev
   \`\`\`

*(Atenção: Os comandos Vite e Tailwind requerem o Node.js instalado na tua máquina.)*
